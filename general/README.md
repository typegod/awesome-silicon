# 通用科学知识

本目录保存无法归入半导体、投资、软件工具等专门主题，但具有长期复用价值的基础科学知识，以及适合上传 GitHub 开源的系列文章归档。

## 系列归档约定

- 一个系列使用一个稳定英文 slug 目录。
- 系列目录根层只放最新版配图文章，命名为 `NN--slug.md`；不为单篇文章再建文件夹。
- 系列图片统一平铺到系列目录的 `imgs/`，文件名增加 `NN--slug--` 前缀，正文统一引用 `imgs/...`。
- 只归档配图版正文；不复制源文、翻译、纯文字稿、提示词、验证报告和发布记录。
- 为方便直接上传 GitHub，系列文章删除开头 YAML 元信息，但保留正文 H1 标题。
- 原费曼项目是写作与审计真源；这里保存的是只读派生归档，不反向覆盖源文章包。
